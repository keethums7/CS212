# For Lab 3 - Part 1
## Setup using uv (ideally)
After downloading, be sure to `cd` into the `lab03_part1` directory first, then
use `uv sync`, and run `python main.py`, e.g.:

### On Linux (adjust for your own OS as needed)
if necessary:
```
cd lab03_part1
```

then:
```
uv sync && \
source .env/bin/activate && \
python main.py
```
